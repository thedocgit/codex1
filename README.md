# Ebook Premium AI

Aplicação web para criar e-books completos com padrão premium, conteúdo informativo e estrutura editorial.

## Execução auto-instalável e autoexecutável

No Linux/macOS, rode apenas:

```bash
./instalar_e_executar.sh
```

O script:
1. valida Node.js e npm;
2. instala dependências automaticamente;
3. inicia o servidor em `http://localhost:3000`.

## Execução manual

```bash
npm install
npm start
```
